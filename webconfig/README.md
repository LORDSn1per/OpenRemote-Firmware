# OpenRemote WebConfig

The remote's own web-based configurator. It's a single, self-contained HTML file
served by the firmware from the SD card (`/www/index.html`) - no separate build
step or external assets. Connect to the remote's Wi-Fi (or its IP address once
joined to a network) to reach it from any browser and manage devices, activities,
macros, themes and icons without needing a computer running Studio.

The version here is the one built into the current firmware release in this repo.
