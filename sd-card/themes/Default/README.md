# OpenRemote Default Themes

These factory themes are prepared for the 240 x 320 OpenRemote LCD. Each theme
includes a browser preview, an editable source image and a dithered RGB565 file
used directly by the firmware.

- Smooth Blue
- Obsidian Silk
- Aurora Glass
- Champagne Noir
- Grand Cinema
- Alpine Ember
- Midnight Penthouse

Keep the files together in `/themes/Default` on the remote SD card.
