# OpenRemote SD Card Structure

This folder is the clean master template for a new OpenRemote SD card.

## Card format

Format the card as **FAT32 / MS-DOS (FAT)** with a **Master Boot Record (MBR)** partition map. Insert the card into the remote before using OpenRemote Studio to prepare it over USB.

## Contents

- `activities`, `devices`, `macros`: created by OpenRemote as the user adds configuration.
- `backups`: full backups created on the remote or through WebConfig.
- `config`: runtime settings generated by the remote.
- `firmware`: recovery or update firmware installed by OpenRemote Studio.
- `icons/Default`: factory icon library.
- `icons/Custom`: user-uploaded icons.
- `irdb`: optional IR database files.
- `logs`: diagnostic logs.
- `themes/Default`, `themes/Custom`: theme files.
- `tmp`: temporary transfer files.
- `www`: WebConfig installed as `index.html` by OpenRemote Studio.

The template intentionally contains no devices, activities, macros, settings, Wi-Fi credentials, firmware, WebConfig, custom themes or custom icons.
