OpenRemote SD Card
Selected versions are recorded in /config/version.json.

This card was prepared by OpenRemote Studio 2.45.

Required format:
- FAT32, shown as MS-DOS (FAT) on macOS
- Master Boot Record partition map
- Do not use ExFAT or GUID Partition Map

OpenRemote Studio preserves an existing runtime.json, devices, activities,
macros, custom icons, custom themes and backups when refreshing a used card.
