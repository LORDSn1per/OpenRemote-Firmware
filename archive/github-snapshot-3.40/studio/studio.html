The SD card stays inside the remote. The card must already be FAT32 / MS-DOS (FAT) with Master Boot Record - a card formatted NTFS or exFAT cannot be reformatted over USB, so if Studio reports the card is unreadable, format it on this computer first, put it back, and finish from the Recovery tab. No firmware .bin is copied to the card; the remote runs from its internal flash.

Recovery
Repair a remote over USB when its WebConfig page cannot be reached. The SD card stays inside the remote.

            

            

              
              
            

            

              
1
Install WebConfigWrites a WebConfig .html to the SD card as www/index.html. Use this when a WebConfig installed incompletely - the remote's own web page cannot replace itself once it is broken.

              
2
Prepare SD CardCreates any missing folders and installs WebConfig, Default icons and Default themes onto the card inside the remote. Existing files are skipped and your data is left alone. Choose a firmware and WebConfig on Remote Config first. Useful if setup step 3 could not finish - for example the card had to be reformatted to FAT32 on a computer.

              
3
Load BackupCopies an OpenRemote backup to /backups on the card and offers to apply it. Full backups replace the configuration; single-category exports (devices, learned, activities, macros, icons, themes) and WebConfig's per-device learned .ir exports merge into it, leaving everything else alone. Anything unrecognised is rejected before sending.

              
              
4
Load .IR FileCopies a Flipper-format .ir signals file straight into /devices, where the remote picks it up as a device. You are warned before overwriting a file of the same name. A WebConfig-exported learned device is OpenRemote JSON rather than a Flipper file, so it is sent to /backups and applied instead - either slot accepts either kind.

              
              
5
Restore Factory SettingsErases devices, activities, macros, custom icons and themes, saved Wi-Fi and settings from the SD card, then rebuilds the empty folders. WebConfig, firmware, SD backups and the Default libraries are kept. The remote restarts afterwards.

Close the Arduino Serial Monitor before using these actions, or the USB port will be busy. Recovery talks to the remote over USB serial only - it does not need Wi-Fi.
